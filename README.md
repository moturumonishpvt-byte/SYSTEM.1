# S.Y.S.T.E.M. 

A personal life tracker inspired by *Solo Leveling*.

The idea is simple: turn your daily routine into a game. Complete quests, earn EXP, level up, improve your stats, and keep track of your progress.

## Features

- **Player stats** — Track your level, EXP, rank, and attributes.
- **Daily quests** — Keep track of your daily tasks and routines.
- **Custom quests** — Create additional quests and earn EXP.
- **Skills** — Add skills and track your progress.
- **Inventory & shop** — Manage items and in-game currency.
- **Save progress** — Keep your progress saved in your browser.

## Getting Started

You'll need [Node.js](https://nodejs.org/) installed.

```bash
git clone https://github.com/moturumonishpvt-byte/SYSTEM.1.git
cd SYSTEM.1
npm install
npm run dev
```

Open the local URL shown in your terminal to start using the app.

## Built With

## Note

Your progress is saved in your browser's local storage. Clearing your browser data may erase it.
